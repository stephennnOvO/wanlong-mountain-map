# 地图与开发限制

## 地图数据

- 部分自行车路线、公园道具布局和建筑外形为示意重建。
- 地形整修、建筑接地和设施尺寸包含影像估读值，不代表实测竣工数据。
- 夜场展示采用对应雪季的参考范围，不提供实时开放信息。

## 构建与维护

- 业务模块通过代码片段组装，共享闭包作用域，修改时需保留加载顺序。
- 地形缓存绑定关键输入文件。修改这些输入后，默认构建会报错；可使用 `npm run build:uncached`。
- 无缓存版本在首次打开页面时计算地形，加载时间较长。
- 自动地形重新烘焙工具尚未纳入项目。
- `app.js`、`shell.html` 和生成数据文件不参与格式化，组装器依赖入口模板中的文本标记。

## 测试范围

自动化测试覆盖资源依赖、桌面和手机尺寸的离线启动、页面错误及横向溢出，不验证现实地理位置的准确性。触屏手势和设备性能仍需在真实手机上检查。
