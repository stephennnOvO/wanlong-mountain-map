# 素材与数据来源

| 文件                                   | 内容                 | 来源与许可                                         |
| -------------------------------------- | -------------------- | -------------------------------------------------- |
| `vendor/three.min.js`                  | Three.js             | 许可证见 `vendor/THREE-LICENSE.txt`                |
| `src/geo-data.js`                      | 地形、建筑与路线数据 | 数据署名见网页地图信息；各数据集的许可清单尚不完整 |
| `data/layouts/`                        | 设施布局与路线修订   | 包含影像核对和示意参数                             |
| `data/terrain/`                        | 地形修订数据         | 包含局部人工整形                                   |
| `data/inputs/local-terrain-cache.json` | 烘焙地形缓存         | 由地形输入及整形逻辑生成                           |

原创代码的 MIT 许可适用于项目代码。OpenStreetMap 来源数据按 [ODbL 1.0](https://www.openstreetmap.org/copyright) 提供。地形数据来源为 Mapzen / USGS，参见 [Mapzen 数据署名说明](https://www.mapzen.com/rights/)。官方雪道原图和餐饮照片请通过雪场官方渠道查阅。
